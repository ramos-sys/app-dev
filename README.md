# My Favorite Series: *Stranger Things*

> *"Friends don't lie."* — Eleven

---

## 🎬 Overview
**Stranger Things** is an American science fiction horror drama television series created by the **Duffer Brothers** for *Netflix*. Set in the 1980s in the fictional town of Hawkins, Indiana, the series centers on numerous supernatural occurrences around the town.

## 🏆 Key Characters & Cast

| Character Name | Actor / Actress | Role / Description |
| :--- | :--- | :--- |
| **Eleven (El)** | Millie Bobby Brown | Telekinetic girl raised in Hawkins Lab |
| **Mike Wheeler** | Finn Wolfhard | Leader of the core group of friends |
| **Dustin Henderson** | Gaten Matarazzo | Quick-witted science enthusiast |
| **Jim Hopper** | David Harbour | Hawkins Chief of Police |

---

## 🍿 Top Reasons to Watch

1. **Nostalgic 80s Aesthetic:** Synthwave soundtrack and retro pop-culture references.
2. **Compelling Storyline:** Mystery surrounding the *Upside Down*.
3. **Character Growth:** Strong character arcs across all seasons.
